# 资源池与开户资料工作流

## 产品行为

邮箱、IP/代理、信用卡、企业文件为四个独立资源池。导入数量不要求相同；记录通过资源 ID 关联各池，不按文件名、显示名称或数组下标反查资料。创建时可手选邮箱、IP、信用卡及企业文件，未指定的名额从未使用资源中顺序补齐。默认 IP 为逐条自动分配，显式选择共享模式才复用代理。

“完整组合”选项要求每条都有四类资源，缺项整批拒绝。常规模式保留未关联创建能力，但预览明确显示缺项。创建预览与保存使用相同的服务端选择函数；预览不占用资源，确认时提交资源 ID 和版本，提交在 SQLite 写事务中重新校验。预览后资源被修改或占用时整批拒绝，不静默换成另一组。已有记录占用的资源，即使状态被误改为未使用，也不会再次自动分配。创建请求仍使用幂等键。

## PDF 导入

- 一份 PDF 对应一份企业资料；多页同一证书不拆成多家企业。每份最大 10 MB、最多 50 页，每批最多 100 份，可继续分批导入。
- 多文件进入独立队列，逐份读取、识别和查重，避免同时把全部 PDF 编码到内存。默认只解析，逐份校对或保存完整项；用户勾选后才自动保存完整、无重复的项。
- 队列状态：等待 → 识别中 → 自动查重 → 可保存 / 待校对 / 重复 / 失败 → 保存中 → 已入池。写入结果不确定时单独标记，禁止自动重试，需先核对资料库。
- 文件内容 SHA-256 与企业注册身份分别判重。输入停止 350 ms 后自动查询全员记录；新输入使旧查询失效，关闭弹窗会取消查询。保存时仍进行事务内全员校验。同一账号的新建操作也不能静默覆盖自己的旧资料。
- 跨账号查询只返回当前输入的冲突原因，不暴露原记录、所属账号或时间。相同企业编号统一大小写、格式符与全角字符，保留前导零；新 CNPJ 中的字母不能作为国家前缀误删。

## 多国识别边界

`lib/license-identifiers.js` 提供可扩展的文本层规则：CNPJ（巴西）、OIB（克罗地亚）、CVR（丹麦）、KRS/NIP（波兰）、SIREN/SIRET（法国）、UEN（新加坡）、ABN/ACN（澳大利亚），以及带 Companies House 上下文的英国公司号。使用标签和上下文，不从文件名、IP 或数字长度猜测国家。

名称、街道、地址第二行、城市、省/州、邮编与注册国家使用多语言字段标签提取，原文保留。未适配版式或其他国家文件可人工录入同一结构。自动识别不等于核实登记真实性、校验号码真伪或保证 Google 接受文件；规则测试使用合成 PDF，实际覆盖需要各版式样本验证。

扫描图片没有可读文本层、密码保护、多个不同 OIB/企业编号、字段缺失时进入人工校对。未配置 OCR 服务，不宣称支持所有扫描件；不伪造缺失地址、个人资料、国家或编号。同一文件包含多个企业时，需拆分或人工核对，一份文件不静默合并多个主体。

## 开户资料面板

企业文件详情支持逐字段复制与整份企业资料复制。每条记录的“开户资料”由服务端按当前登录账号读取其关联 ID，展示原始企业名称、注册国家、街道、地址第二行、城市、省/州、邮编、注册号，以及该条记录的邮箱、IP、信用卡别名和网站。缺项明确标记；复制整份时只包含实际存在值，不复制占位文案。

已保存资料通过详情中的“校对资料”编辑，带版本校验，保留原 PDF 和已分配记录，并同步关联记录的名称。已有企业编号只读；查重排除项必须属于当前账号，不能用其他账号的记录 ID 绕过全员查重。

投放国家独立于企业注册国家。账单国家、账户类型、币种、时区和付款方式由实际业务确认，不从代理所在国家推断。复制摘要不包含邮箱密码、2FA、代理密码、完整卡号或 CVV；已有敏感字段解锁流程保持适用。

## 验证与运行边界

后端测试覆盖只读预检、跨账号隐私、新建本人重复拒绝、两账号同时提交、PDF 重新导出与修改编号、组合预览不占用资源、手选顺序、完整组合、占用状态错误修正及开户资料账号隔离。`scripts/license-pools-ui.cjs` 使用隔离测试库验证真实页面操作、慢查询、网络故障、队列与复制，在远程桌面测试中执行。

当前免费部署的持久存储限制仍然存在。本功能不改变套餐、磁盘、数据库路径或密钥。生产级持久数据、OCR、对象存储与大规模后台任务需要另行配置基础设施，不能用前端队列替代它们。
# 内嵌原件预览

单份 PDF 导入、已有企业资料详情/修改与批量校对均接入 File Viewer 3.2.2。使用 `@file-viewer/web` 和 `@file-viewer/renderer-pdf` 的按需组合，不引入全部格式依赖。当前上传范围仍为 PDF；扫描件可预览，但自动识别仍限于原有文本层流程。

预览在浏览器中进行。未保存文件直接作为 File 传入；已保存原件通过现有、带会话和所有权校验的 `/api/licenses/:id/pdf` 接口读取，再作为命名 File 传入组件。不得把带私密凭据的 URL 交给外部服务。原件下载接口及备份格式保持不变。

`npm run build:viewer` 从锁定的本地 npm 依赖生成 ESM 分块、匹配的 PDF worker、CMaps、字体、WASM 和许可证。`pretest`、`prestart`、桌面启动及构建钩子自动构建；新克隆后直接调用 `node server.js` 前须先运行该命令。生成目录不提交 Git，由安装/构建流程重建，并包含在桌面应用的 `public/**` 中。静态路由仅接受启动时枚举的该目录内普通文件，不暴露任意文件路径、符号链接或用户上传目录。

预览 CSP 保留同源脚本限制，仅增加 PDF 解码需要的 WASM 编译权限，以及本地生成的 worker/font/image Blob 支持；未添加任意外站或 JavaScript `unsafe-eval`。许可证在生成资源目录随运行文件分发。
