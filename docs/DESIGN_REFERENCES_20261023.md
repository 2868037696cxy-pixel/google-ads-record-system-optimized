## 具体交付

- 总览：显示四类未占用库存、完整组合的数量上限与缺项。估算不替代真实组合核对，也不预占资源。
- 创建：左右分区组织基础信息与资源分配；三个可点击步骤指向对应区域，根据输入与已有校验更新当前步骤。低频字段按需展开，返回页面保留草稿及展开状态。
- 资源库：邮箱、IP、信用卡与企业文件分别给出用途说明、对应搜索提示与“去组合资源”入口；已有筛选与分页继续保留。
- 快捷操作：可点击侧栏入口，或按 Ctrl/⌘+Shift+K。支持中文与多关键词、上下键选择、Enter 打开、Esc 取消与焦点回到原处。Ctrl/⌘+K 优先保留当前列表搜索，非列表页打开快捷操作。
- 可访问性：输入法组合确认不触发命令；弹窗焦点循环忽略 tabindex=-1 选项；打开业务弹窗时快捷键不会替换当前任务；减少动效模式关闭弹窗动画。
- 校对：保留原有原件/字段双栏、复制反馈、批量逐份校对、自动查重、错误重试和移动布局。

## 验证方式与边界

`npm run test:workspace` 启动隔离数据库与沙盒浏览器，以三个独立测试账号分别运行工作台、资源池和 PDF 预览测试。覆盖 320、390、800、1280、1440px 宽度、中文输入法事件、键盘焦点、返回后的草稿保留、资源缺项、提交前不写入、PDF 翻页缩放与失败重试。Windows CI 同时运行该验证和既有原生桌面流程。

设计参考不代表供应商背书、素材授权转移、商业服务订阅或所有平台的人工验收。本轮不改变套餐、数据库位置、真实分配事务、查重规则、注册策略和原件权限。
