# 工作台流程可靠性补审

2026-10-20，在设计系统基础上检查表单、恢复、导出、同步与异步生命周期。范围为当前 PR 的真实程序，不包含生产部署或历史数据自动修复。

## 本轮发现与修复

| 问题 | 原有影响 | 实现与证据 |
| --- | --- | --- |
| 打包版离线页来源被误拒 | 同一原生框架的不同 JS 包装对象造成 IPC 拒绝，无法显示连接信息和重连 | 提取桌面来源守卫，按窗口/主框架原生 ID 与 URL 校验；离线能力仅允许精确的规范化资源，继续拒绝其他窗口、子框架与外部页面 |
| 连续换备份文件，旧读取晚到 | 新文件无效时，旧文件仍可重设待恢复内容 | 文件修订号、局部候选解析、关闭后忽略；确定性回归先失败再通过 |
| 敏感导出在锁定后返回 | 弹窗虽关闭，晚到结果仍触发文件下载 | 弹窗取消信号、下载前授权期限/代次校验；先失败再通过并接入 Electron 回归 |
| 桌面解锁请求晚于锁定完成 | 旧响应可把客户端重新置为已授权 | 解锁与锁定代次校验；先失败再通过 |
| 弹窗内 Ctrl+R 刷新背景 | 输入核对期间全局同步重建页面，干扰任务 | 弹窗内拦截快捷键但不发起同步；先失败再通过 |
| 创建完成后替换用户新任务 | 锁定已关闭创建弹窗，但晚到成功响应仍关闭/替换后开的弹窗 | 结果弹窗与错误只属于原确认入口；确定性回归先失败再通过，已提交的数据仍正常同步 |
| 仅提交按钮停用 | 保存时仍可关窗、改字段，误判为取消并重复提交 | 统一 pending 生命周期覆盖创建/编辑/导入/执照/删除/恢复，保留控件原状态；Electron 验证双击、Esc、失败恢复 |
| 失败只用瞬时提示 | 原因消失后无法确定下一步 | 就地持续错误，保留草稿和重试入口；错误绑定原弹窗 |
| 完整同步重建输入与滚动 | 光标、选区和核对位置丢失 | 同页保存焦点/选区/滚动上下文，不保存文本副本；Electron 验证 |
| 恢复展示未验证的外层统计 | 可编辑元数据看起来像已核验的备份内容 | 展示文件名与服务端校验说明，增加覆盖确认，换文件清空确认 |
| 执照文本识别期间可保存 | 识别结果尚未稳定就提交旧字段 | 识别修订号与源文本校验，识别期间停用保存，失败恢复入口 |

`tests/workbench-lifecycle.test.js` 使用实际生产函数和受控 I/O 复现异步时序；不是只检查源码是否包含某个字符串。`test:ux` 验证真实 Electron 的 DOM、焦点、禁用态、取消与截图；`test:desktop:remote` 验证合成 HTTPS 服务上的加密备份恢复。以对应提交的 CI 结果判定通过。

旧 round73 回归在 Windows 候选中出现未能结束的运行；补齐测试超时与 Electron 收尾的失败退出，保留全部业务断言。设置 `process.exitCode` 加终止子进程不足以保证 Playwright 传输挂起时退出；超时现在明确失败并结束隔离测试进程，不据此推断真实产品已通过关闭验收。

## 仍需后续工作

| 优先级 | 剩余不足 | 推进边界 |
| --- | --- | --- |
| 高 | 老版本可能留下关联 ID 与展示快照不一致的数据 | 已接入本人范围的逐批检查、差异核对与版本保护修复，见 `DATA_INTEGRITY.md`；真实历史仍须用户核对，不按名称猜测或自动改写归属 |
| 高 | 更大规模与跨服务器个人迁移 | 已新增 v3 加密任务、1 MiB 分块续传与隔离验证恢复，见 `PERSONAL_BACKUP_TASKS.md`；仍有 512 MiB / 每表十万行边界，且依赖原账号与密钥，未承诺任意规模或跨服务器迁移 |
| 中 | 业务状态与请求编排仍集中于较大的 app.js | 已提取组件行为与独立的关联检查、备份任务控制器；后续按记录查询、创建草稿、资源导入继续迁移，保持接口与回归稳定 |
| 中 | 桌面高密度表格仍需实际业务体验评估 | 自动回归覆盖多尺寸与软件缩放；仍需真实 Windows DPI、阅读器、系统文件选择与长时间核对验收 |
| 中 | legacy 样式与部分历史页面规则尚未全部迁移 | 按组件逐步替换并核对截图，避免一次清理破坏登录/原生桌面差异 |
| 依赖需求 | 团队邀请、细粒度 RBAC、审计筛选 | 先明确后端权限和数据范围；继续保持个人明细隔离，不用前端角色判断代替鉴权 |

没有合并或部署生产。本轮没有重写历史关联、扩大可浏览的数据范围，或修改真实服务器配置。
