# 工作台设计系统与组件契约

本规范与 `DESIGN_SYSTEM_DESKTOP.md` 共同约束真实工作台。目标是让长时间核对、批量录入和资源管理稳定、清楚、可预测。所有设计与功能都落在现有原生 HTML/CSS/JS 中。

## 实现边界

| 层 | 唯一职责 | 文件 |
| --- | --- | --- |
| 设计令牌 | 字体、字号、颜色、间距、尺寸、圆角、焦点、动效和层级 | `public/design-tokens.css` |
| 既有页面骨架 | 历史布局与尚未迁移的页面样式，固定在最低优先级 | `public/styles.css` 的 `legacy` 层 |
| 工作台布局 | 导航、内容区、密度、面板与桌面响应布局 | `public/ui-foundations.css` 的 `foundations` 层 |
| 原生组件 | 按钮、字段、表格、选择、反馈、弹窗、设置、核对和导出组件 | `public/ui-components.css` 的 `components` 层 |
| 组件行为 | 安全模板、SVG 图标、空状态、状态文本、按钮忙碌态、字段语义和弹窗生命周期 | `public/ui-components.js` |
| 业务与数据 | 本人数据、查询状态、创建草稿、资源分配、导出、版本冲突 | `public/app.js`、`licenses.js`、`security.js` |

级联顺序显式声明为 `legacy → tokens → foundations → components`，防止旧选择器凭特异性反压新规范。不得继续追加第 N 个“最终补丁”，也不得在业务数据层决定颜色或字号。业务模块仍是渐进迁移的原生模块；本轮没有更换框架或重写鉴权。

## 字体与版式

| 用途 | 令牌 | 规范 |
| --- | --- | --- |
| 正文 | `--font-body` | 14px，行高 1.55，常规字重 400 |
| 输入标签与表格内容 | `--font-label` | 13px，标签字重 600，内容 400–500 |
| 辅助说明与表头 | `--font-caption` | 12px，不能承担唯一错误或状态信息 |
| 面板标题 | `--font-section` | 15px，600–700 |
| 弹窗标题 | `--font-dialog` | 18px，700，行高 1.28 |
| 页面标题 | `--font-title` | 27px，700，行高 1.28 |
| 编号与时间 | `--mono` | 系统等宽回退；数字启用等宽宽度 |

Windows 优先 Segoe UI Variable Text / Segoe UI，中文回退微软雅黑 UI，其他系统使用系统字体。无需第三方字体网络请求。国家、公司名称、操作说明使用正文字体；仅编号、域名和时间等数据使用等宽。中文文字不使用负字距。间距使用 4/8/12/16/20/24/32px 令牌。

## 按钮与按键

| 类型 | 视觉与用途 | 尺寸 |
| --- | --- | --- |
| 主按钮 | 当前任务的主要提交或继续动作；每个操作区域只突出一个 | 高 40px |
| 次按钮 | 返回、取消、选择、刷新、导出等辅助动作 | 高 40px |
| 小按钮 | 表格、分页和密集工具栏 | 最小高 36px |
| 危险按钮 | 删除、恢复覆盖；显式影响范围，保留危险色与文字 | 最小高 36px |
| 图标关闭 | 有明确无障碍名称“关闭”，可见焦点 | 最小 36×36px |
| 侧栏导航 | 图标与文字并列，不缩成空白按钮 | 最小高 42px |

统一 default / hover / focus-visible / active / disabled / busy 状态。按下不缩放控件，不引起表格或按钮位移。加载时保留动作文字，禁用重复提交，并提供 `aria-busy`。停用和占用原因必须有文字，不能只降低透明度。

| 按键 | 行为 |
| --- | --- |
| Tab / Shift+Tab | 按文档顺序移动；弹窗内循环，不进入背景 |
| Enter / Space | 激活原生按钮、导航和可复制字段 |
| Esc | 取消弹窗草稿；关闭列菜单并回到触发入口 |
| Ctrl+K | 聚焦当前记录或资源列表的搜索框 |
| Ctrl+R | 重新读取服务端数据，保留内存中的创建草稿 |

删除确认初始焦点放在取消。提交中的创建核对弹窗阻止普通关闭；敏感信息锁定仍可主动关闭弹窗并擦除数据。弹窗关闭后恢复原入口，入口已被重建时回到当前导航。

## 字段与反馈

- 每个输入控件有可识别标签；域名错误紧邻字段，设置 `aria-invalid` 并在主动提交时恢复焦点。
- 创建前统一处理域名大小写、网址前缀与路径，再检查重复、500 条上限、指纹范围与已有资源库存。空资源库沿用既有服务端允许“不关联”的行为。
- 输入内容留在当前会话内，不保存到浏览器偏好；显示偏好只保存列名和密度。
- 确认创建前展示域名、指纹范围与资源模式。取消不写库，确认使用既有幂等键，结果页显示实际已创建数量。
- 查询有 ready / loading / error 三态。等待或失败时保留上次结果并显式标记，旧表格暂不可操作；失败有常驻重试入口。
- 防抖开始立即作废旧请求；旧成功和旧失败不能覆盖新查询。敏感锁定同时作废在途的明文请求。
- 写入成功、刷新失败单独呈现常驻提示，明确“已保存/更新/删除”，避免用户再次提交。

## 表格与批量范围

- 默认后端分页每页 50 条，允许 25/50/100/200；排序直接发送服务器白名单值，不对当前页伪装全量排序。
- 搜索和翻页保留跨页选择；全选仅当前页；选择条始终说明“本页”和“其他页或筛选外”数量，并允许清空。
- 导出先选“所选”或“本人全部”，明确筛选不影响“本人全部”范围。AdsPower 继续二次授权；CSV 继续不输出凭据。
- 复选框列固定 44px，指纹列从 44px 开始冻结；两列不得重叠，指纹不得被省略。长名称换行；水平滚动区域可由键盘到达。
- 搜索/筛选与显示/导出使用独立工具行；列菜单根据可用空间向上或向下展开，有自己的滚动区，不被面板裁切。行操作保持可见，不依赖 hover 才能发现。
- 表头有 scope，复选框与状态选择有记录名称或资源编号。可复制字段可用 Enter/Space 操作。
- 占用数取服务端对本人全部记录的统计，跨页引用也显示“已关联 N 条记录”，继续阻止非法释放和删除。
- 编辑或清空资源关联时，四类资源的关联 ID 必须与快照字段在同一事务落库。不能只更新邮箱、代理或公司名称等展示字段；后续资源同步、占用计数和释放都依赖真实关联。

## 弹窗与组件生命周期

共享 `WorkbenchUI.dialog` 管理标题、背景 inert、默认焦点、Tab 循环、Esc、关闭与焦点恢复。所有业务弹窗继续使用现有 `openModal` / `closeModal` 入口，不另造第二套。

标题与操作区不收缩，只有正文滚动。包含 form 的解锁、改密弹窗同样遵守这一结构。长营业执照表单在较低窗口和 125%/150% 缩放下仍须能到达确认区。原生文件选择器和服务端授权边界不由组件接管。

公共组件模板统一转义文本和属性；图标为本地 SVG 白名单；组件模块不能访问 API、账号、凭据或持久化。组件 API 冻结，业务行为通过 `data-action` 显式连接。

## 验收入口

`npm test` 验证服务端与公共模板安全；`npm run test:ux` 运行真实 Electron 的完整交互和布局回归。Windows CI 在原有桌面、远程、F15、round73 和设计基础回归之前执行新 UX 回归，并上传截图。

新回归覆盖八个业务页面、1280×720 / 1440×900 / 1920×1080、125%/150% Electron 缩放、查询失败与过期响应、跨页选择/导出、创建核对与重复点击、同步失败后的恢复、冻结列和弹窗键盘循环。软件缩放不能代替真实 Windows 显示器 DPI、系统阅读器与日常业务格式的人工验收。

附加回归检查自动指纹编号随同步更新、敏感锁定后晚到的明文响应不进入状态、列菜单恢复默认入口和八个页面所有可见表单控件的无障碍名称。截图在关闭动画后采集，避免把入场过渡帧当作最终视觉效果。

跨页占用回归还发现并修复了既有资源编辑路径仅修改内存中的关联 ID、没有把它放入 SQL 更新字段的问题。新增 HTTP 回归覆盖四类资源更换、清空、占用统计、后续资源字段同步和冲突原子拒绝。修复前更换/清空用例以关联 ID 未改变的预期断言失败，修复后通过。此修复保障之后的编辑；不根据名称或快照自动猜测、改写历史记录的归属。
