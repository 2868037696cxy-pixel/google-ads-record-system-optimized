# 账号工作台 · Windows 桌面版

面向 Windows 10/11 x64 的本地账号与资源工作台。保留邮箱、代理、信用卡、营业执照资料库、资源分配、记录管理和 AdsPower / CSV 导出功能。

## 直接使用

- 安装版：运行 `AdsWorkbench-1.1.0-x64.exe`，可选择安装目录。
- ZIP 版：完整解压 `AdsWorkbench-1.1.0-x64.zip`，运行目录内的 `AdsWorkbench.exe`。不要只拷贝 EXE，运行库和 resources 目录同样必需。
- 使用安装包无需另外安装 Node.js，不依赖浏览器、云端端口或 GitHub 网站。
- 应用只启动一个实例，窗口位置和尺寸会保留。本地 API 使用动态端口与每次启动生成的桌面访问令牌。

数据保存在 `%APPDATA%\AdsWorkbench\data.json`，与安装目录分离。不要把它当成加密保险库：其中包含资源和原 PDF 的数据，完整备份也包含这些内容。

## 营业执照与原 PDF

1. 打开「营业执照」→「批量导入」，选择 PDF（最大 10 MB / 50 页）。
2. 校对组织名称、法定名称、街道地址、公寓/套房门牌号、邮编、城市和 CVR 注册号。组织名称与法定名称必填；没有独立套房号时留空。
3. 点击「确认保存」。仅确认后才保存原文件；关闭弹窗不会留下临时上传件。
4. 点击资料库或记录中的公司名称，即可打开基础信息面板，字段可单独复制。
5. 点击「打开原 PDF」使用 Windows 默认阅读器查看原件；「打开文件位置」打开资源管理器定位文件。

支持丹麦 Business Authority 注册证书的自动识别，也支持中文/英文标签的结构化文本。扫描件没有文本层时需要手动填写；本版本未集成 OCR。系统按实际证书提取，不使用示例公司的信息替代文件内容。

原 PDF 按 SHA-256 去重，保存在完整数据快照中；打开时在 `documents` 目录生成 PDF 文件。完整备份和恢复携带原件，不依赖上传文件的原始路径。同名组织再次导入 PDF 会更新资料并关联新原件。JSON 数据较大时建议分批导入，不适合海量文档归档。

## 备份与恢复

- 侧栏「备份」或 `Ctrl+Shift+S`：导出全部记录、资源及 PDF。
- 侧栏「恢复」或 `Ctrl+Shift+O`：选择完整备份并确认；替换前自动备份旧数据。
- 每次成功保存会在 `backups` 中保留旧版本，最多 30 份。
- 数据损坏时应用不会用空数据覆盖原文件，启动时可选择有效备份恢复。
- 「数据目录」打开本地保存位置。卸载程序默认保留应用数据。

原有网页版的 `data.json` 可通过「恢复」导入；仅保存了文本的旧营业执照不含原 PDF，需要补充导入原文件。

## 开发和构建

需要 Node.js 22.13+（推荐 Node.js 24 LTS）、npm 和 Windows x64：

```powershell
npm ci
npm run desktop
```

运行测试并构建安装版和 ZIP 版：

```powershell
npm test
npm run test:desktop
npm run build:win
```

输出在 `dist`。`npm run build:dir` 只生成 Windows 运行目录。

本地网页开发可用 `npm start`，默认只绑定本机；`PORT`、`HOST` 和 `DATA_FILE` 可配置。桌面应用自动管理端口和数据路径，不需要手动运行这个命令。`ADS_DESKTOP_DATA_DIR` 仅用于隔离开发/测试数据。

Linux 构建机可以生成 Windows ZIP 运行版。本次云构建机的 Wine 无法加载 Windows 系统库，NSIS 安装版构建未成功；请使用 Windows 本机或仓库中的 Windows desktop 工作流生成安装程序。工作流已经提供，尚未在 GitHub 上运行。Linux 上运行桌面测试需要 X 显示服务；测试脚本的容器参数不会关闭 Windows 产品的渲染器沙箱。

## 验证范围与交付限制

API/存储测试覆盖失败回滚、资源占用与释放、重复指纹、批量限制、文件损坏和完整备份。桌面测试覆盖启动、隔离的渲染器、访问令牌、PDF 识别及校对、原件完整性、记录分配、备份恢复与连接重试。

桌面测试自动替代原生文件选择框和 PDF 阅读器调用，以便重复运行。Windows 安装、卸载、SmartScreen 提示及实际 PDF 阅读器需要在 Windows 机器上验收。当前构建没有发行者代码签名，尚未设置自动更新服务器。
