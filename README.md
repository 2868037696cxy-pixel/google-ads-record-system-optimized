# 谷歌广告记录系统 v3.0

广告投放数据记录系统，数据存储在**服务端 SQLite 独立数据库**中，不依赖浏览器缓存。

## 🚀 快速开始

```bash
npm install
npm start
```

访问: http://localhost:3000

冒烟测试：`npm run smoke`（自动验证核心 API、乐观锁、备份恢复、登录鉴权）

## ✨ 功能

- SQLite 独立数据库（WAL 模式，外键 + CHECK 约束）
- **乐观锁**：多窗口同时编辑时，旧版本保存会被拒绝并弹窗提示，避免互相覆盖
- **自动备份**：每次保存自动快照，保留最近 30 份；支持手动备份与一键恢复
- **产品/市场可配置**：系统设置页自由增删，不再改代码
- 广告管理与统计（预算/消耗/单量/ROI/毛利率）
- 多序列趋势图（消耗/收入/单量双轴，悬停查看，图例可开关）
- 数据导入导出（JSON/CSV/Excel）
- 每日数据「复制昨日」一键录入，广告编号自动递增
- 深色模式、批量操作、成本预警、撤销/重做、键盘快捷键
- **可选访问密码**：设置 `APP_PASSWORD` 环境变量后启用登录保护

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+S | 保存 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| N | 新增广告 |
| Escape | 关闭对话框 |

## 🔒 访问密码（可选）

```bash
APP_PASSWORD=你的密码 npm start
```

启用后所有 `/api/*` 接口需要登录（token 存于 sessionStorage，关闭标签页失效）。

## ☁️ 部署到 Render

> ⚠️ 免费计划没有持久盘，重启/重新部署会丢失数据库。如需长期使用请选择 Starter 及以上计划并挂载磁盘。

```bash
# render.yaml 已包含持久盘配置，直接用 Render 的 Blueprint 部署即可
```

关键环境变量：

| 变量 | 说明 |
|------|------|
| `DB_PATH` | 数据库文件路径，Render 上设为 `/data/ads.sqlite`（指向持久盘） |
| `APP_PASSWORD` | 访问密码，公网部署务必设置 |
| `PORT` | 端口，Render 自动注入 |

本地/自有服务器部署时，`DB_PATH` 默认为项目下 `data/ads.sqlite`，做好文件备份即可。

## 🗄️ 数据安全说明

- 全量保存走 SQLite 事务（删除→插入→版本号+1→自动备份），原子完成
- 乐观锁版本号 `rev`：`GET /api/ads` 返回当前版本，`PUT /api/ads` 必须携带匹配的 `rev`，否则返回 `409`
- 备份表与业务表在同一数据库文件：建议定期用「导出 JSON」做异地备份
- 恢复备份前会自动快照当前数据，可再次恢复回来
